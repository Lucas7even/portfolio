# Portfólio - Lucas Hudson

O site apresenta informações acadêmicas, projetos desenvolvidos e um jogo da forca criado como parte do portfólio.

## Tecnologias utilizadas

- React
- Next.js
- JavaScript
- CSS
- HTML

## Funcionalidades

- Página inicial com apresentação pessoal
- Seção sobre formação acadêmica
- Apresentação de projetos
- Galeria
- Área de contato
- Jogo da Forca
- Interface responsiva

## Jogo da Forca

O projeto possui uma página dedicada ao Jogo da Forca.

O jogador precisa descobrir a palavra escolhendo as letras disponíveis. Cada letra incorreta aumenta o número de erros.

### Regras

- A palavra é escolhida aleatoriamente.
- O jogador possui até 6 erros.
- Letras corretas são reveladas na palavra.
- Ao descobrir a palavra, o jogador vence.
- Ao atingir 6 erros, o jogador perde.
- É possível iniciar uma nova partida.
